# DELIVERY-ACK-ROOT-01 — shared lifecycle
All order, staff, debt, collection, manual share and Chat media adapters must separate business commit, recipient intent, file creation, upload, message attachment, and downstream delivery. Durable key = original event + recipient + media slot. Financial commit is never retried by media recovery. A transport ACK is not an attachment ACK; attachment is not a push delivery ACK. Retry only idempotent stages with exact identity, bounded lease, fresh authorization, current revision and independent recipient status. Unknown provider outcome is review, not resend. No silent empty message beyond the recovery SLA. A completed image must be linked to live media and Storage bytes. A deleted message or revoked recipient must never be restored by retry. No new keyboard, scroll, or notification presentation owners.
